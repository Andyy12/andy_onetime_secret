# CLAUDE.md - GoDatalize Secretos Developer & AI Assistant Guide

This document provides architectural guidance, coding standards, development workflows, and system invariants for developers and AI agents (Claude, Antigravity) working on **GoDatalize Secretos** (a hardened, customized fork of Onetime Secret).

---

## 1. Project Overview

**GoDatalize Secretos** is an enterprise-grade, zero-knowledge, ephemeral secret sharing application. It allows users to securely transmit sensitive credentials, passphrases, API keys, and notes with one-time view limits and automatic expiration.

- **Primary URL**: [https://www.godatalize.com](https://www.godatalize.com)
- **Primary Brand**: GoDatalize
- **Product Name**: GoDatalize Secretos
- **Architectural Paradigm**: Zero-knowledge encryption, client-side cryptographic utilities, decoupled session storage, single-use access tokens.

---

## 2. Technology Stack

### Frontend
- **Framework**: Vue 3 with Composition API (`<script setup lang="ts">`)
- **State Management**: Pinia stores with strict typing
- **Styling**: Tailwind CSS 3.x with custom theme tokens (`brand-500`, `gray-*`, dark mode support)
- **Icons**: Phosphor, Tabler, Heroicons (via SVG sprites and `OIcon` component)
- **Internationalization**: `vue-i18n` with 30 compiled language bundles
- **Build Tool**: Vite with TypeScript support
- **Testing**: Vitest + `@vue/test-utils`

### Backend
- **Core**: Ruby 3.4+ / Sinatra / Rack
- **Datastores**: Redis (sessions, ephemera, rate limits) + PostgreSQL (optional multi-tenant auth)
- **Security**: CSP, HSTS, Secure Cookies, Web Crypto API on client

## 3. Core Repository Invariants

Always respect these repository invariants:

1. **Session Keys**: Session data is stored under string keys (`session['key']`), NEVER Ruby symbols. Reads and writes agree on string keys by design.
2. **Timestamps**: All timestamps are stored and manipulated in UTC. Conversion to user locale occurs only at the display edge in the frontend.
3. **Brand & Repository Redirection**:
   - All references to original repositories (`github.com/onetimesecret`) must remain pointed to `https://www.godatalize.com`.
   - The primary website URL in translations (`web.COMMON.website_url`) is `https://www.godatalize.com`.
4. **SessionSidecar Semantics**: Single-use keys in Redis have short TTLs with delete-on-read semantics. Key expiration represents privacy enforcement, not data loss.
5. **No Direct Test Invocations for Ruby**: Never execute `rspec`, `rake spec:*`, or `try` directly. Use the isolated lane runner `tests/lanes/run` to avoid touching dev databases or ambient environment variables.

## 4. Key Frontend Modules & Components

### 4.1 Cryptographic Password Generator
- **Composable**: `src/shared/composables/usePasswordGenerator.ts`
  - Uses `crypto.getRandomValues` (CSPRNG).
  - Entropy calculator computing Shannon bits:
    $$\text{Entropy} = L \times \log_2(R)$$
    where $L$ is length and $R$ is character pool size.
  - Configurable options: length (6–64), uppercase, lowercase, numbers, symbols, ambiguous exclusion (`il1Lo0O|;:.,'` etc.).
- **UI Component**: `src/shared/components/forms/PasswordGeneratorConfig.vue`
  - Monospace preview with re-roll spin animation.
  - Interactive length slider synced with number input.
  - Checklist of character groups with auto-safeguard (at least one pool active).
  - Visual 5-segment strength meter.
  - Emits `use-password` event to insert generated value into parent forms.
- **Form Integrations**:
  - `src/apps/secret/components/form/SecretForm.vue`
  - `src/apps/workspace/components/forms/WorkspaceSecretForm.vue`

### 4.2 QR Code Generator & Modal
- **Component**: `src/shared/components/ui/SecretQrModal.vue`
  - Generates high-contrast QR code from secret link via `qrcode` package.
  - Includes download button saving high-res PNG.
- **Trigger**: Integrated in `src/apps/secret/components/receipt/SecretLink.vue`.

### 4.3 Branded Display Case Parity
- **Component**: `src/apps/secret/components/branded/SecretDisplayCase.vue`
  - Implements `useDecryptReveal` for character-by-character animated decryption.
  - Dynamic lock badge indicator.
  - Auto-destruction warning alert ("Burned secret").

### 4.4 Quick Secret Templates
- **Component**: `src/apps/secret/components/form/SecretContentInputArea.vue`
  - Interactive chip buttons:
    - **Usuario / Clave**: `Usuario: \nContraseña: `
    - **Base de datos**: `HOST: \nPORT: \nUSER: \nPASSWORD: \nDATABASE: `
    - **Variables .env**: `API_KEY=\nSECRET_KEY=\nDATABASE_URL=`
  - Appends or sets content without losing existing user text.

### 4.5 Developer Terminal / cURL Snippet
- **Component**: `src/apps/secret/components/receipt/SecretLink.vue`
  - Renders collapsible shell box with formatted `curl -X POST` command.
  - Includes quick copy button.

## 5. Development Workflows & Commands

### 5.1 Environment Setup on Windows
When working in PowerShell, execution policy may restrict `.ps1` wrapper scripts. Always run `pnpm` and Node tools via `cmd.exe /c "npx pnpm ..."`:
```powershell
cmd.exe /c "npx pnpm install"
cmd.exe /c "npx pnpm dev"
```

### 5.2 Running Vitest Tests
```powershell
cmd.exe /c "npx pnpm vitest run src/tests/composables/usePasswordGenerator.spec.ts"
cmd.exe /c "npx pnpm vitest run src/tests/components/PasswordGeneratorConfig.spec.ts"
cmd.exe /c "npx pnpm vitest run src/tests/components/SecretQrModal.spec.ts"
cmd.exe /c "npx pnpm vitest run src/tests/apps/workspace/components/layout/WorkspaceFooter.spec.ts"
```

### 5.3 Internationalization (i18n) Workflow
Translations live in `locales/content/{locale}/*.json`.
Whenever keys are added or modified:
1. Update source keys in `locales/content/en/*.json` and `locales/content/es/*.json`.
2. Compute and apply content hashes:
   ```powershell
   python locales/scripts/i18n content hashes --apply
   ```
3. Compile all 30 target locales:
   ```powershell
   python locales/scripts/i18n content compile --all
   ```
4. Never manually edit files in `public/web/locales/` or `dist/` — they are build artifacts.

## 6. Coding Style & Conventions

- **Vue Files**:
  - Always use `<script setup lang="ts">`.
  - Prefer Vue 3 composables (`use*`) for stateful logic.
  - Provide complete accessibility labels (`aria-label`, `role`, `aria-live`).
- **TypeScript**:
  - Strict type checking enabled.
  - Define explicit interfaces in `src/types/` or co-located composables.
- **Styling**:
  - Use utility classes from Tailwind CSS.
  - Ensure full Dark Mode support using `dark:*` prefixes.
  - Adhere to brand colors (`brand-500`, `brand-600`, `brand-700`).
- **Git Commits**:
  - Use Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`).
